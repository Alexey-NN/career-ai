# Career-AI — Описание проекта

## Название

**Career-AI** — ИИ-ассистент для поиска работы на топ-позиции

## Проблема

Поиск работы на позиции CEO / CEO-1 / COO — это не массовый отклик на сотни вакансий, а точечная работа с ограниченным числом релевантных предложений. Ручной мониторинг hh.ru, LinkedIn, Telegram-каналов занимает часы. Анализ соответствия вакансии профилю, написание сопроводительных писем и подготовка к собеседованиям — повторяющиеся задачи, которые можно автоматизировать, сохранив качество и персонализацию.

## Пользователь

Топ-менеджер с 20–30-летним стажем, ищущий позицию CEO / CEO-1 / COO в Москве. Опыт — немецкие компании в РФ, fashion-ритейл, IT-консалтинг, внедрение 1С. Не рассматривает релокацию. Ожидает конкретных результатов без лишних объяснений.

## Основная функция

Автоматизировать полный цикл работы с вакансиями: поиск → фильтрация → анализ соответствия → сопроводительное письмо → подготовка к собеседованию. Сервис собирает вакансии с hh.ru, LinkedIn и Telegram-каналов, отсеивает нерелевантные, сравнивает требования с резюме кандидата и выдаёт готовые артефакты.

## Формат результата

| Артефакт | Формат | Содержание |
|---|---|---|
| Сканирование вакансий | `.md` | Таблицы вакансий по приоритету (топ / средний / не рекомендуются), ссылки, зарплаты, обоснование |
| Анализ вакансии | `.md` | Совпадения и пробелы vs резюме, % соответствия, рекомендация «откликаться / нет» |
| Сопроводительное письмо | `.docx` | Письмо под конкретную вакансию, стиль и язык — по запросу |
| Подготовка к собеседованию | `.md` | Вероятные вопросы, аргументы из опыта, проработка слабых мест |

## Минимальный функционал (MVP)

1. **Поиск вакансий** — сканирование hh.ru по 4 запросам (генеральный директор, CEO, COO, исполнительный директор) с фильтрацией по Москве и зарплате от 400K ₽
2. **Фильтрация** — удаление ассистентских позиций, узкоспециализированных замов, отраслевых несовпадений (нефтегаз, фарма, девелопмент), позиций несоответствующего калибра
3. **Анализ соответствия** — сравнение требований вакансии с резюме кандидата, расчёт % совпадения, список пробелов с рекомендациями по перекрытию
4. **Сопроводительное письмо** — генерация письма под вакансию с акцентом на цифры и достижения
5. **Сохранение результатов** — структурированные папки по вакансиям: описание, анализ, сопроводительное

## Технологии

| Слой | Технология | Обоснование |
|---|---|---|
| Язык | Python 3.12+ | Основной язык проекта, экосистема AI/ML |
| Web-фреймворк | Flask | Лёгкий, достаточен для API и простого UI |
| Frontend | HTML / CSS / Jinja2 | Минимальный UI для MVP, шаблоны Flask |
| AI / LLM | Claude API (Anthropic) | Анализ вакансий, генерация писем, сравнение профилей |
| Парсинг hh.ru | requests + BeautifulSoup / Jina Reader | Чтение страниц вакансий и результатов поиска |
| Парсинг Telegram | Jina Reader (публичные каналы) / Telethon | Чтение постов из каналов |
| LinkedIn | Selenium / Playwright | Скрапинг профиля и вакансий |
| Генерация .docx | python-docx | Создание Word-файлов с сопроводительными письмами |
| Хранение данных | JSON / Markdown-файлы | Простое хранение без БД для MVP |
| Планировщик | APScheduler / cron | Периодический скан вакансий |
| Деплой | Docker | Упрощение запуска и переносимости |
