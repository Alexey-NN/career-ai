## Инструкции

Выполни запрошенное действие. Если действие не указано — выполни `status`.

### `status` — Сводка по проекту

1. Прочитай `CLAUDE.md` — извлеки ключевые настройки: целевые позиции, каналы, критерии фильтрации
2. Проверь `data/vacancies/` — сколько папок с вакансиями, даты последних сканов
3. Проверь `git status` — есть ли незакоммиченные изменения
4. Выведи краткую сводку: структура, последние сканы, статус git

- Период: из аргумента или 7 дней по умолчанию

После скана выведи таблицу вакансий с ссылками на hh.ru и рекомендациями.

### `readme` — Обновление README.md

1. Прочитай текущий `README.md`
2. Прочитай `CLAUDE.md` — проверь актуальность: каналы, агенты, критерии
3. Сравни README с реальным состоянием проекта:
   - Структура каталогов совпадает?
   - Агенты описаны?
   - Telegram-каналы актуальны (только рабочие)?
   - Технологии соответствуют?
4. Внеси необходимые правки в README.md
5. Спроси: «Сохранить изменения и запушить на GitHub?»

---

### `errors` — Проверка ошибок и проблем

1. **Файлы проекта**: проверь существование ключевых файлов (CLAUDE.md, README.md, скрипты)
2. **CLAUDE.md консистентность**: каналы в алгоритме Telegram совпадают с таблицей статуса? Агенты описаны?
3. **Git**: незакоммиченные изменения? Конфликты?
4. **.gitignore**: личные файлы (резюме, вакансии, .docx, .env) исключены?
5. **Дубликаты**: есть ли повторяющиеся вакансии в data/vacancies/?
6. **Ссылки**: проверь что ссылки в README кликабельные и корректные

Выведи отчёт: ✅ OK / ⚠️ Warning / ❌ Error для каждой проверки.

---

### `publish` — Подготовка к публикации на GitHub

1. Запусти проверку `errors`
2. Проверь что `.gitignore` исключает все личные файлы:
   - Резюме (*.docx с именами, PDF)
   - Вакансии (data/vacancies/)
   - .env, .mcp.json
   - .claude/, .obsidian/, tmp/
3. Проверь что в staged нет личных данных: `git diff --cached --name-only`
4. Если есть проблемы — выведи список, попроси исправить
5. Если всё чисто — спроси: «Делаю git add, commit и push. Подтвердить?»
6. После подтверждения: `git add -A && git commit && git push origin master`
