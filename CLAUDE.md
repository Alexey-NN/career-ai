# Как работаем

- Сначала результат — в чат. Если нужен файл Word, агент спрашивает: «Сохранить в Word?»
- Стиль сопроводительных писем — агент спрашивает каждый раз (формально-деловой, живой, с акцентом на цифры и т.д.)
- Язык результата — агент спрашивает: русский или английский
- Ответы конкретные, со ссылками и предложениями по дальнейшим шагам
- Перед масштабной задачей (переработка профиля, анализ десятка вакансий) — показать план и дождаться подтверждения; мелкие задачи выполнять сразу.

- Когда ставится задача проанализировать вакансию по ссылке или с описанием вакансии в промпте это означает что нужно создать папку для вакансии в папке \data\vacancies, в нее сохранить структурированное описание вакансии в файле md, результаты анализа сравнения требований вакансии и моего резюме с рекомендациями в файле md, сформировать сопроводительное письмо с акцентом на цифры, на русском языке и сохранить в формате Word, предложить дальнейшие шаги.

1. **Анализ соответствия вакансии резюме** — сравнить требования вакансии с опытом в резюме, указать совпадения и пробелы, предложить как перекрыть пробелы, дать рекомендацию: откликаться или нет.

4. **Подготовка к собеседованию** — составить список вероятных вопросов, подобрать аргументы из опыта, проработать слабые места.

### Алгоритм поиска вакансий

**Цель:** найти открытые вакансии CEO / CEO-1 / COO / исполнительный директор в Москве и отфильтровать по уровню кандидата.

**Шаг 1 — Составить поисковые запросы.** Использовать 4 варианта названий должности:
- `генеральный директор`
- `CEO`
- `COO`
- `исполнительный директор`

Для каждого — сформировать URL поиска на hh.ru:
```
https://hh.ru/search/vacancy?text=<запрос>&area=1&order_by=publication_date&search_period=<период>
```
Параметры: `area=1` (Москва), `order_by=publication_date` (новые сверху), `search_period` — по запросу пользователя (1 / 3 / 7 / 30 дней).

При необходимости расширить поиск на другие площадки (SuperJob и др.) через Brave Search с `site:` фильтром.

**Шаг 2 — Прочитать страницы результатов.** Через Jina Reader (`https://r.jina.ai/<URL>`) загрузить каждую страницу поиска hh.ru. Извлечь: название должности, компания, зарплата, ссылка на вакансию.

**Шаг 3 — Первичный отбор.** Убрать нерелевантные:
- Ассистентские позиции (помощник, ассистент, секретарь, водитель генерального директора)
- Зарплата ниже 400K ₽ (если не указана — оставлять на проверку)
- Не Москва (если не оговорено иное)
- Узкоспециализированные замы (зам. по производству, зам. по строительству и т.п. — если не CEO-1 по смыслу)

**Шаг 4 — Проверка релевантности.** Прочитать полные описания оставшихся вакансий через Jina Reader и убрать те, где требования несовместимы с профилем кандидата:
- Жёсткие отраслевые требования (нефтегаз, пищевое производство, строительство/девелопмент, фармацевтика и т.п.) — если у кандидата нет опыта в этой отрасли
- Специфические лицензии и сертификаты (аттестат ЦБ РФ, квалификация главного инженера и т.д.)
- Явное указание «не подходит из Enterprise» или аналогичные дисквалифицирующие условия
- Релокация за пределы Москвы (если кандидат не готов к переезду)
- Вакансии, где должность называется CEO/COO, но по сути это позиция уровня 200–300K (не соответствует калибру кандидата)

Вакансии с пожеланиями по отрасли (а не требованиями) оставлять, помечая как «пограничные»

**Шаг 5 — Структурировать результат.** Разделить на группы:
- **Топ-уровень** (от 600K) — CEO/CEO-1 позиции
- **Средний уровень** (400–600K) — CEO/CEO-1 позиции
- **COO / Операционные директора** (потенциальные CEO-1)

Для каждой вакансии: должность, компания, зарплата, ссылка.

**Шаг 6 — Сохранение результатов.** Обязательно сохранить итоговый анализ в файл `.\data\vacancies\hh-ru-scan-<дата>\hh-ru-scan-<дата>.md`. Формат файла: критерии фильтрации, таблицы вакансий по группам (топ-приоритет, средний приоритет, не рекомендуются), для каждой релевантной вакансии — полное описание с анализом совпадения с профилем, в конце — рекомендации по следующим шагам.

**Шаг 7 — Рекомендации.** Указать 3–5 вакансий с наивысшим приоритетом с кратким обоснованием (отрасль, зарплатная вилка, соответствие профилю). Спросить, какие вакансии анализировать детально.

### Алгоритм поиска вакансий в Telegram

**Цель:** найти открытые вакансии CEO / CEO-1 / COO / исполнительный директор в Москве через Telegram-каналы и проанализировать их на соответствие профилю кандидата.

**Каналы для проверки (по приоритету):**

2. **@vacancyCRC** — middle/top менеджмент, платное размещение, CRC работает с CEO-уровнем

**Шаг 1 — Чтение каналов.** Через Jina Reader (`https://r.jina.ai/https://t.me/s/<username>`) прочитать последние посты каждого канала. Если канал недоступен через Jina (закрытый, приватный) — отметить это и перейти к следующему.

**Шаг 2 — Сбор вакансий.** Из каждого канала извлечь:
- Должность
- Компания (если указана)
- Зарплата
- Локация
- Ключевые требования
- Отдельно пометить посты о кандидатах (не вакансии)

**Шаг 3 — Первичный отбор.** Убрать нерелевантные по тем же критериям, что и для hh.ru:
- Ассистентские позиции
- Зарплата ниже 400K ₽ (если не указана — оставлять)
- Не Москва
- Узкоспециализированные замы
- Отраслевые требования, несовместимые с профилем (нефтегаз, пищевое производство, строительство/девелопмент, фармацевтика)
- Позиции уровня 200–300K, названные CEO/COO

**Шаг 4 — Анализ соответствия профилю.** Для каждой релевантной вакансии:
- Сравнить требования с опытом в резюме (`.\data\260507_CV_HH_RU_Structured.md`)
- Рассчитать процент совпадения
- Определить сильные стороны и пробелы
- Дать рекомендацию: откликаться / откликаться с оговоркой / не откликаться

**Шаг 5 — Структурировать результат.** Разделить вакансии на группы:
- **Топ-приоритет** (совпадение ≥70%) — откликаться
- **Средний приоритет** (30–70%) — откликаться с оговоркой
- **Низкий приоритет** (<30%) — не откликаться, кратко пояснить почему

Для каждой вакансии: должность, компания, зарплата, локация, % совпадения, рекомендация.

**Шаг 6 — Проверка дубликатов.** Перед созданием новых папок проверить `.\data\vacancies\` на наличие уже проанализированных вакансий. Если вакансия уже анализировалась — сослаться на существующий анализ, не дублировать.

**Шаг 7 — Сохранение результатов.** Создать папку `.\data\vacancies\<дата>-<короткое-название>\` с файлами:
- `vacancy_description.md` — структурированное описание вакансии
- `analysis.md` — анализ соответствия резюме с рекомендациями
- `cover_letter.docx` — сопроводительное письмо (по запросу)

Для вакансий с совпадением ≥70% — предложить создать полный анализ (папка + описание + анализ + сопроводительное).

**Шаг 8 — Рекомендации.** Указать вакансии с наивысшим приоритетом. Спросить, какие анализировать детально. Напомнить о прямых контактах.
